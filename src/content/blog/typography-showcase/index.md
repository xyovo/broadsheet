## 二级标题

正文段落。中英混排时会自动留出间距，比如 Astro、Tailwind CSS 和 Pagefind 这些词嵌在中文里不会挤在一起。这里有 **加粗**、_斜体_、`行内代码` 和一个[站内链接](/blog)，以及一个[外部链接](https://astro.build)。

### 三级标题

三级标题会一并进入右侧目录。目录只在有标题的文章里出现。

## 引用

> 引用块适合放整段摘录或者一句结论。
>
> 支持多个段落。

## 代码块

带语言标注的代码块会高亮，右上角有复制按钮：

```ts
type Post = {
  title: string;
  date: Date;
  tags: string[];
};

const formatTags = (post: Post) => post.tags.join(" / ");
```

不标语言的代码块保持等宽字体，不做高亮：

```
src/content/blog/
└── typography-showcase/
    └── index.md
```
